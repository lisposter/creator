# ETF 开箱 Cover Preset

Use for ETF 开箱 series and ETF-focused finance articles.

## Text

- topic: `美股 ETF 开箱`
- anchor: ticker, e.g. `SOXX`, `DRAM`, `EUV`, `FOTO`
- subtitle: explain the mechanism or exposure, not return promise
- Do not make distribution yield or short-term performance the main selling point.

## Visual Style

- Draw the mechanism behind the ETF.
- Use compact system / portfolio / supply-chain diagram on the right.
- Avoid generic wealth or stock-market cliches.
- Avoid real issuer logos.
- Ticker can be the main anchor.

## Topic Visual Map

- SOXX: semiconductor supply chain nodes, chip design / equipment / foundry.
- DRAM: HBM stack, memory bandwidth, data feeding GPU.
- EWY: Korea market basket, Samsung / SK hynix gravity, KRW exposure.
- EUV: lithography beam, wafer, photonics / data link.
- FOTO: laser, fiber, silicon photonics, data-center optical interconnect.
- XQQI: Nasdaq-100 exposure, boosted exposure, covered call income layer.

## Forbidden

- Do not imply guaranteed yield.
- Do not make distribution yield the visual protagonist.
- Do not use fake official logos.
- Do not create chart-heavy dashboard covers.
- Do not draw a generic K-line chart as the main image.

## Verification

- Ticker and title must be exact.
- Visual should make the ETF's actual exposure clearer.
- If the article says the name is narrower than the holdings, the visual should reflect the broader basket rather than only the ticker's literal meaning.
