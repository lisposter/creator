# Finance Tutorial Handdrawn Cover Preset

Use for Innomad finance tutorials that explain broker tools, bank/broker account workflows, thinkorswim features, quote data, fractional share orders, and trading indicators.

## Purpose

The cover should feel clean, practical, handmade, and recognizable as the recent Innomad blue tutorial cover style. It should not feel like a corporate SaaS dashboard or stockbroker ad.

## Canvas

- Ratio: 5:2.
- Default size: 2500x1000.
- Background: solid `#006e99`.
- Add very subtle paper / grain texture if possible.
- Avoid heavy gradients, glassmorphism, fake dashboards, stock-photo atmosphere, and marketing-poster effects.

## Typography

- Generate the background without title text.
- Use `references/text-overlay.md` for final title.
- Title: white handwritten Chinese style.
- Default placement: visually centered, usually center-left or center, with enough empty space around it.
- Long titles can use 2-3 lines. Keep the most important phrase on the strongest line.

## Line Art

- Use white / pale-cyan hand-drawn line art.
- Keep line weight thin to medium, slightly organic, not corporate vector icons.
- Add only tiny amber accents when useful.
- Put most illustrations on the right, lower edge, or corners so the title remains clean.
- Do not reuse the same line art mechanically. Redraw according to the article topic.

## Topic Visual Map

- 盈透 / 嘉信懒人包: two broker terminal windows, checklist, folder tabs, route map.
- 522 + 5: broker account, bank card, ACH / wire path, document checklist, small bank building.
- 嘉信实时报价: quote feed, ticker tape, data plug, brokerage terminal without real logo.
- thinkorswim 碎股: order ticket, decimal share quantity, broker terminal, small `0.25 share` style notation.
- ATR / APTR: candlestick ranges, bracketed true range, stop-loss line, volatility ruler.
- Sizzle Index: options chain, call / put heat, unusual volume sparks, radar / signal motif.
- VWAP: intraday price path around weighted average line, scale / balance motif.

## Forbidden

- Do not use real broker logos unless the user explicitly provides assets and asks for them.
- Do not draw giant K-line charts as the whole cover.
- Do not use generic money bags, rockets, luxury objects, or exaggerated wealth visuals.
- Do not place decorative line art behind the title if it hurts readability.
- Do not let image generation invent title text.

## Verification

- Background must read as `#006e99`.
- Title must be exact and white.
- Line art must not overlap the title.
- Final output must be no-text background plus local text overlay when Chinese title is present.
