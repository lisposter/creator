# Topic Visual Map

Use this as a shared visual vocabulary across cover presets.

## ETF / Stocks / Allocation

- Broad semiconductor ETF: chip nodes, equipment, foundry, supply-chain graph.
- Memory / HBM: stacked memory, bandwidth lanes, data feeding GPU.
- Country ETF: country market basket, currency node, major-company gravity.
- Photonics / optical ETF: laser, fiber, silicon photonics, data-center optical interconnect.
- Option income ETF: underlying index exposure, option overlay, income layer, capped upside boundary.
- Portfolio allocation: weights, satellite orbit, risk-return balance.

## Broker / Bank / Trading Tools

- Broker account setup: checklist, document folder, account node, approval path.
- Bank transfer / ACH / wire: bank building, card, transfer route, settlement clock.
- thinkorswim / TOS: terminal outline, watchlist, order ticket, options chain, quote column; do not make a real UI screenshot.
- Fractional shares: decimal share quantity, notional amount converted into shares.
- Real-time quotes: ticker feed, data cable, quote refresh, bid / ask columns.
- Order types: route, condition node, execution state, cancel/fill markers.

## Options / Indicators

- Options flow: call / put chain, unusual volume, radar signal, heat marks.
- ATR / APTR: true range bracket, stop-loss line, volatility ruler.
- VWAP: intraday price path around weighted average line, balance / anchor motif.
- Sizzle Index: heat gauge, signal spikes, options-chain intensity.

## AI Tools

- LLM workflow: prompt node, model node, tool node, output node.
- Coding assistant: editor-like abstract panel, diff marks, task graph; avoid fake product UI.
- Automation: trigger, queue, worker, result.

## Digital Nomad / Life

- Travel workflow: route line, passport, laptop, calendar, location nodes.
- Time freedom: calendar blocks, open path, simple horizon.
- Personal finance / FIRE: time-money balance, runway, cash-flow path.
