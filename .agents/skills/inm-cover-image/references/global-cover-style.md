# Innomad Cover Global Style

Use this for all Innomad cover images before loading a preset.

## Brand

- Brand text: `Innomad 一挪迈`.
- Tone: rational, restrained, clean, technically literate.
- The cover should feel like a former programmer explaining an investment or technology system.
- Do not make it look like a stockbroker ad, course poster, trading group promo, or generic wealth poster.

## Default Layout

- Native 5:2 raster cover.
- Strong left typography.
- Right-side concept diagram or topic visual as secondary support.
- Main title must be the first visual center.
- Keep generous breathing room.
- Important text must be readable and exact.

## Default Color Direction

- Default finance-tech background: offshore blue `#004D6B`.
- Allowed depth: `#00384F`, `#003247`, `#005B7A`.
- Main text: near-white `#FAFAF7`.
- Positive / output / filled path: `#05A882`.
- Topic accent: `#006E99`.
- Risk / warning: muted red or orange only when necessary.

## Visual Rules

- Draw the mechanism behind the article, not literal decoration.
- Allowed mechanisms: modules, nodes, relationships, path, stages, arrows, weights, risk boundary, order-rule state, portfolio distribution.
- Keep diagrams compact and unframed.
- Avoid huge K-lines, fake dashboards, fake broker UI, stock-photo atmosphere, rockets, money bags, coin rain, bull-bear fights, and luxury objects.
- Avoid rounded UI cards, large translucent panels, decorative bars, gradient blobs, and bokeh orbs.
- Do not make outside brand logos the protagonist.

## Text Rules

- Product names, company names, tickers, and numbers may appear if exact.
- Chinese title text must be exact. If uncertain, use `text-overlay.md`.
- Avoid tiny unreadable labels and fake microtext.
- Do not use image-model generated Chinese for final title.

## Verification

Before finishing:

- Open the final image.
- Check all title text against the article / user request.
- Check no clipped text, no overlap, no elements too close to the edge.
- Check the visual mechanism matches the article.
- Check the cover still reads well at small preview size.
