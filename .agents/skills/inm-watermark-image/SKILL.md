# Innomad 图片防盗水印

只叠加水印，不修改、重绘、裁切、移动或缩放原图内容。使用确定性的本地 Pillow 脚本，不让生成模型重画输入图片。

## 固定规格

水印文字必须逐字保持如下内容，不包含代码块标记或外层引号；斜线前一个空格、后两个空格，`Innomad` 与「一挪迈」之间没有空格，域名是 `.com`：

```text
Innomad一挪迈 /  innomad.com
```

- 3 列 × 3 行，共 9 条，均匀覆盖画面；行间轻微错位。
- 从左下向右上倾斜 22°，中性灰 `#707070`。
- 基础透明度默认 11%，可在 10%–12% 内调整；信息密集处进一步降低。
- 支持中文的干净无衬线字体，常规字重；字号为图片短边的约 3%。
- 不添加描边、阴影、发光、底色或边框。
- 标题、数字、图表和数据标签的可读性优先；必要时让水印在这些局部区域完全透明。
- 保持原图像素尺寸、宽高比、DPI（如有）、色彩配置和透明通道；只在水印实际覆盖的像素上混合灰色。最终输出 PNG。

## 工作流程

1. 定位并打开无水印原图。目视检查没有旧水印，不能仅凭文件名或元数据认定原图干净。当前会话已确认的原图不重复询问。
2. 只有带水印版本时，请用户提供无水印原图；不要去除、覆盖或叠加旧水印。生成图应先保存无水印版本，再执行本 skill。
3. 使用下面的脚本，输出到新的文件名，通常为 `posts/{slug}/imgs/{name}-watermarked.png`。原图只读，不写入 `data/obsidian/30-Outputs/`，不创建额外报告文件。
4. 脚本会根据边缘及局部密度淡化水印，但这只是启发式保护，不具备语义识别能力。打开输出，逐项检查标题、数字、图表和数据标签；遗漏的重要区域用 `--protect-box` 指定。
5. 调整参数时始终重新读取同一份无水印原图，输出新的 PNG；绝不把上一次水印结果作为输入。
6. 交付 PNG 链接并简述规格。需要后续上传或 X 占位时引用最终 PNG，保留无水印原图。不要再自动转成 WebP。

## 脚本

`SKILL_DIR` 为本文件所在目录。脚本需要 Python 3 和 Pillow；依赖缺失时可用 `uv run --no-project --with pillow python` 运行，无需修改全局 Python 环境。

```bash
uv run --no-project --with pillow python "${SKILL_DIR}/scripts/add_watermark.py" \
  /absolute/path/original.png \
  /absolute/path/name-watermarked.png \
  --original-confirmed
```

可选参数：

- `--opacity 0.10`：基础透明度，允许 0.10–0.12。
- `--protect-box 80,40,900,120`：保护区域的 `X,Y,宽,高`，单位为原图像素；可重复指定。区域内原图像素完全不变。
- `--font /absolute/path/font.ttf`、`--font-index 0`：中文无衬线常规字体；默认查找 Arial Unicode、Noto Sans CJK 或微软雅黑，不以缺字方框代替中文。

`--original-confirmed` 表示已经完成原图检查，不是让用户额外确认一次。脚本拒绝覆盖原图、已存在的输出、带本脚本标记的输入、明显的水印输出文件名及非 PNG 输出。标记存在于 PNG 元数据中，不另建 sidecar 文件；**未检测到标记不等于没有旧水印**。

支持常见 8 位 RGB、RGBA、灰度和索引色原图（索引色展开为等值像素）。遇到高位深、CMYK、动画或多页图片时停止并说明限制，不通过转换、降位深或截取首帧假装保持原图不变。
